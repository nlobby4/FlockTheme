# FlockTheme
A browser extension made to mod flockmod and make it customizable

- It will work with any browser that allows extensions. Firefox is more complicated.

- The example used here is chrome, but general idea is the same for any browser that allows extensions! including Edge.

---
**STEPS TO DOWNLOAD**
1. Click the Green button that says "<> Code"
2. Click Download ZIP
3. Go to your Folders > Downloads > You should see ZIP file called "FlockTheme-main.zip"
4. Right click and Extract all
5. Within "FlockTheme-main" is the <u>"FlockMod Themer and Mod" folder</u>, that's what you need
6. You can delete the ZIP file, keep the extracted file.
7. Open Chrome and type chrome://extensions/ in the search
8. Make sure "Developer Mode" is turned on in your browser's extension tab
9. Click on "Load unpacked" on the top left corner
10. Choose the extracted file (The folder titled "Flockmod Themer and Mod" found)
11. Make sure the extension is turned on
12. Reload Flockmod and enjoy!
---
**How to update & Extra mods**
- When updating, you can remove/uninstall the outdated extension and it's files. Then follow step 1-12 with the new one
- Your saved settings/themes/imported images should be saved.
- If you're using another extension, it should still work the same, you can toggle on/off any features included in this mod to favor another!
